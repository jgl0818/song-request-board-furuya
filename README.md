# 直播点歌网站（最新歌单版）

这是一个纯静态网站，可直接部署到 GitHub Pages、Vercel、Cloudflare Pages 或任意静态服务器。

## 当前曲库
- 657 首唯一歌曲
- 162 位歌手
- 9 类曲风
- 665 次分类收录
- 8 首歌曲保留双曲风标签
- 歌名、歌手、live 标记及曲风均以 `直播歌单_曲风分类_进一步修改_紧凑版.docx` 为准

## 文件
- `index.html`：点歌页面，歌曲数据已经内嵌，上传后可直接运行。
- `songs.json`：同一份最新曲库的数据备份，便于以后继续更新。
- `README.md`：本说明。

## 如果你已经部署过 GitHub Pages
不需要重新建仓库，也不需要更换公网网址。把仓库根目录原来的 `index.html`、`songs.json`、`README.md` 替换成这里的新文件并 Commit，GitHub Pages 会更新原网站。

## 二维码
页面部署到公网后，二维码会自动使用当前页面 URL，因此只要 GitHub Pages 的网址不变，二维码入口也不需要手工修改。

## 点歌交互
- 歌名/歌手为完整精确匹配，可单独填写，也可同时填写。
- 按曲风按钮可浏览对应歌曲。
- 点击“点这首”会复制 `点歌：歌名 - 歌手`。
